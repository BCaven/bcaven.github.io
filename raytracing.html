GPU Path tracer in C++ and Slang

Built a GPU-accelerated path tracer in Slang and C++ using Vulkan

A full writeup of the project can be found on GitHub.
Here is a list of notable features:

  • Sphere, Triangle, and Gaussian Splat primitives
  • Instancing via Transform primitives (location, rotation, scale)
  • Progressive path tracing with temporal accumulation
  • Binary AABB interior nodes
  • Wide K-DOP interior nodes
  • Arbitrary nested transforms
  • Arbitrary nested instances

CPU Path tracer in C++

Built a Monte Carlo path tracer in C++ based on the tutorials RaytracingInAWeekend, RaytracingTheNextWeek, and RaytracingTheRestOfYourLife.

In addition to the base functionality from the tutorials, I implemented multi-core tile based rendering, instanced triangle mesh structures with custom UV maps, nested Bounding Volume Hierarchies, and a custom file format to import meshes into the raytracer from Blender.
I also added support for Gaussian Splats as native objects so they support reflections, shadows, and relighting.

Further work is being done on a ray tracer in C++ and Slang using Vulkan.
